# Saurabh Parthe — Portfolio

A cinematic, production-grade portfolio for a Distributed Systems & AI Infrastructure Engineer. Built with Next.js 15, TypeScript, TailwindCSS, Framer Motion, Three.js, GSAP, and Lenis smooth scroll.

## Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** TailwindCSS
- **Animation:** Framer Motion, GSAP
- **3D / Visuals:** Three.js, @react-three/fiber, @react-three/drei
- **Scroll:** Lenis (momentum smooth scrolling)
- **Icons:** lucide-react

## Sections

1. Hero — Cinematic neural-network topology
2. Engineering Identity — Core expertise
3. Featured Projects — Distributed systems, AI, observability
4. System Design — Architecture showcase
5. Experience — Timeline
6. Tech Stack — Animated grid
7. Engineering Metrics — Animated counters
8. Research / Blog — Engineering writing
9. About — Engineering philosophy
10. Contact — GitHub, LinkedIn, Email, Resume

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm start
```

## Deployment

Optimized for Vercel free tier. Deploy directly from GitHub.

## Project Structure

```
src/
├── app/                # Next.js App Router pages, layout, metadata
├── components/
│   ├── layout/         # Navbar, Footer
│   ├── sections/       # Hero, Projects, Experience, etc.
│   ├── ui/             # Reusable UI primitives
│   └── visuals/        # 3D / canvas visualizations
├── constants/          # Data — projects, experience, skills, nav
├── hooks/              # Custom React hooks
├── lib/                # Utilities, animation presets
└── types/              # Shared TypeScript types
```
